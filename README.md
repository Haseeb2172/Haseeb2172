## `01 / story`

My interest in artificial intelligence started with a simple question:

> How can a machine turn raw information into a useful decision?

That question led me to Python, data analysis, statistics, and machine learning.

At first, making a notebook run felt like progress. Now I am learning to ask better questions.

Why did the model make that prediction? Is the evaluation actually fair? Did I introduce data leakage? Can another developer reproduce the result? What happens when the system receives data it has never seen before?

I am still early in the journey, but I am taking it seriously. This profile is where I document the work, mistakes, experiments, and improvements that will shape the engineer I become.

## `05 / standards`

```text
01  Understand the problem before choosing the model.
02  Establish a baseline before increasing complexity.
03  Treat data leakage as a software defect.
04  Measure failures, not only the best result.
05  Make every serious project reproducible.
06  Write documentation that respects the reader's time.
07  Never claim what the repository cannot prove.
```
